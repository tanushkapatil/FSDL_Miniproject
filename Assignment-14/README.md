# Assignment 14

**Category:** Logic-Based JavaScript

## Aim / Problem Statement
Write a program that accepts a string input and performs operations such as reversing, converting to uppercase/lowercase, and calculating its length.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Responsive design (media queries)
- CSS Grid
- Flexbox
- Google Fonts

## Source Code
- `script.js`
- `string.html`
- `style.css`

## How to Run
Open `source-code/string.html` in any modern browser (double-click the file), or serve the folder:

```bash
cd source-code
python -m http.server 8000
# then open http://localhost:8000/string.html
```

## Steps Performed
1. Designed the page structure in HTML.
2. Styled the layout with CSS.
3. Added the interactive behaviour in `script.js`.
4. Ran the program in the browser and captured the output on desktop and mobile widths.
