# Assignment 18

**Category:** Logic-Based JavaScript

## Aim / Problem Statement
Build a Notes Application where users can add and delete notes, with data stored using localStorage.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Web Storage API (localStorage)
- Responsive design (media queries)
- CSS Grid
- Flexbox
- Google Fonts

## Source Code
- `notes.html`
- `script.js`
- `style.css`

## How to Run
Open `source-code/notes.html` in any modern browser (double-click the file), or serve the folder:

```bash
cd source-code
python -m http.server 8000
# then open http://localhost:8000/notes.html
```

## Steps Performed
1. Designed the page structure in HTML.
2. Styled the layout with CSS.
3. Added the interactive behaviour in `script.js`.
4. Ran the program in the browser and captured the output on desktop and mobile widths.
