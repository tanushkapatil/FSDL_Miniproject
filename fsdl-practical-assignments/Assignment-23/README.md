# Assignment 23

**Category:** HTML + CSS Design

## Aim / Problem Statement
Create a Personal Portfolio Webpage with sections: About, Skills, Projects, and Contact.

## Technologies Used
- HTML5
- CSS3
- Responsive design (media queries)
- CSS Grid
- Flexbox
- Google Fonts

## Source Code
- `portfolio.html`
- `style.css`

## How to Run
Open `source-code/portfolio.html` in any modern browser (double-click the file), or serve the folder:

```bash
cd source-code
python -m http.server 8000
# then open http://localhost:8000/portfolio.html
```

## Steps Performed

2. Styled the layout with CSS.
3. Built the layout using HTML and CSS only.
4. Ran the program in the browser and captured the output on desktop and mobile widths.
