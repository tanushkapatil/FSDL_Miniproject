# Assignment 10

**Category:** Interactive UI Components

## Aim / Problem Statement
Develop an FAQ Accordion where clicking a question expands/collapses the answer section.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Responsive design (media queries)
- Flexbox
- Google Fonts

## Source Code
- `faq.html`
- `script.js`
- `style.css`

## How to Run
Open `source-code/faq.html` in any modern browser (double-click the file), or serve the folder:

```bash
cd source-code
python -m http.server 8000
# then open http://localhost:8000/faq.html
```

## Steps Performed
1. Designed the page structure in HTML.
2. Styled the layout with CSS.
3. Added the interactive behaviour in `script.js`.
4. Ran the program in the browser and captured the output on desktop and mobile widths.
