# Assignment 24

**Category:** HTML + CSS Design

## Aim / Problem Statement
Build an Image Gallery with Category Filtering using HTML, CSS, and JavaScript.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Responsive design (media queries)
- CSS Grid
- Flexbox
- Google Fonts

## Source Code
- `imagefilter.html`
- `script.js`
- `style.css`

## How to Run
Open `source-code/imagefilter.html` in any modern browser (double-click the file), or serve the folder:

```bash
cd source-code
python -m http.server 8000
# then open http://localhost:8000/imagefilter.html
```

## Steps Performed
1. Designed the page structure in HTML.
2. Styled the layout with CSS.
3. Added the interactive behaviour in `script.js`.
4. Ran the program in the browser and captured the output on desktop and mobile widths.
