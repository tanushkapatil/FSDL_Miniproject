# Assignment 20

**Category:** HTML + CSS Design

## Aim / Problem Statement
Create a Student Registration Form with fields such as Name, Email, Gender, Course, and Address, and apply proper styling.

## Technologies Used
- HTML5
- CSS3
- Responsive design (media queries)
- Flexbox
- Google Fonts

## Source Code
- `studentregister.html`
- `style.css`

## How to Run
Open `source-code/studentregister.html` in any modern browser (double-click the file), or serve the folder:

```bash
cd source-code
python -m http.server 8000
# then open http://localhost:8000/studentregister.html
```
